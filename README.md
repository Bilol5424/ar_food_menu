# AR Food Menu — демо-приложение (Flutter)

Тестовое мобильное приложение для проверки концепции **3D/AR QR-меню**:
сканируешь QR → открывается меню → смотришь блюдо в 3D и ставишь его
на свой стол в **AR** через камеру. Android сейчас, код готов к iOS.

> Это **демо-флоу для теста на телефоне**, не полный SaaS. Бэкенд (Super
> Admin / Restaurant Admin / Customer, Supabase) — следующий этап.

## Что внутри
- **Сканер QR** — `mobile_scanner` (камера).
- **Меню** — список блюд, ингредиенты, аллергены.
- **3D/AR-вьюер** — Google `<model-viewer>` через `model_viewer_plus`.
  Кнопка AR запускает **Scene Viewer** (Android) и **Quick Look** (iOS).
- **Переключение блюд** — в 3D-вью (нижняя панель). Подробнее про AR ниже.

## Как собрать APK

Платформенная папка `android/` **не лежит в репозитории** — она
генерируется скриптом `tool/prepare.sh` (он же добавляет разрешения
камеры/интернета и intent для AR).

### Вариант A — GitHub Actions (без установки чего-либо)
1. Создай репозиторий на GitHub и залей туда содержимое этой папки.
2. Открой вкладку **Actions** → workflow **Build Android APK** уже настроен
   и запустится сам при пуше в `main` (или запусти вручную — *Run workflow*).
3. По окончании сборки скачай артефакт **ar-food-menu-apk** —
   внутри `app-release.apk`.
4. Перекинь `.apk` на Android-телефон и установи
   (разреши «установку из неизвестных источников»).

### Вариант B — локально
Нужны Flutter 3.3+ и Java 17 (плюс Android SDK / Android Studio).
```bash
cd ar_food_menu
bash tool/prepare.sh          # создаёт android/ и патчит манифест
flutter build apk --release   # сборка
# Готовый файл:
#   build/app/outputs/flutter-apk/app-release.apk
adb install build/app/outputs/flutter-apk/app-release.apk   # или скопируй вручную
```
Для живой отладки на подключённом телефоне: `flutter run`.

## Как протестировать
1. Установи и открой приложение.
2. Нажми **«Сканировать QR-код»** и наведи камеру на QR из файла
   `demo_qr.html` (открой его в браузере на компьютере). Любой QR тоже
   откроет демо-меню — отсканированное значение покажется сверху.
   Либо нажми **«Открыть демо-меню (без QR)»**.
3. В меню нажми **«Смотреть в 3D / AR»** на любом блюде.
4. Покрути модель пальцами. Нажми иконку **AR** (внизу-справа) и наведи
   камеру на стол — блюдо встанет на поверхность.
5. Внизу переключай блюда — модель меняется в 3D-вью.

## Важно про AR (ограничение Apple)
«Переключать блюда **внутри** AR-камеры» бесшовно на iPhone в браузере/
системном AR нельзя: iOS Quick Look — отдельное системное приложение без
доступа к интерфейсу. Поэтому флоу такой: переключение блюд — в 3D-вью,
а AR показывает выбранное блюдо. На Android (Scene Viewer) — так же.
Настоящее переключение внутри сессии возможно только через WebXR (только
Android) или платный WebAR-движок. Для продакшена рекомендован текущий
подход — он бесплатный и работает на всех телефонах.

## Замена демо-моделей на реальные
В `lib/data/sample_menu.dart` у каждого блюда поле `glbUrl` указывает на
**публичную модель-заглушку**, чтобы флоу работал сразу. Замени `glbUrl`
на ссылку (или asset) с реальным 3D-сканом блюда в формате `.glb`. Для
iOS Quick Look позже добавь `.usdz` в поле `usdzUrl`.

## Переход на iOS (позже)
```bash
flutter create --platforms=ios .
```
В `ios/Runner/Info.plist` добавь `NSCameraUsageDescription`. AR через
Quick Look заработает при наличии `usdzUrl` у блюд.
